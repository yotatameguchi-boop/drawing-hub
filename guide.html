Drawing Hub

紙の図面を、チームで検図する

原図を撮って取り込み、版を重ねて比べ、図面の位置を指したまま指摘を交わすためのツールです。ここでは最初の登録から、日々の検図の回し方までをまとめます。

Drawing Hub を開く →

01 / STARTはじめの3ステップ

表示名を入れる

下タブの設定を開いて、自分の名前を入力します。指摘・返信・赤入れ・検図結果に、この名前が記録されます。最初に必ず済ませてください。

工事をつくる

ホームのプロジェクトを作成から、工事名称・工事番号・設計段階を登録します。あわせて公開範囲（オープン／プライベート）を選びます。あとから切り替えできます。

図面を登録する

ホームの図面を登録で、図面番号（A-101）と図面名称（1階平面図）、分野と縮尺を入れます。この時点では中身が空の「図面カード」ができます。

02 / IMPORT原図を取り込む

図面カードを開いて 版を追加。取り込み方は5つあります。取り込むたびに Rev.A → Rev.B → Rev.C と版が積み上がります。

カメラで撮影大判図面はこれが最短です。真上から撮る → 四隅の○を図面枠に合わせる → 仕上げ「白飛ばし」→ プレビュー → 登録。台形の歪みが直り、紙の影と黄ばみが飛びます。
画像ファイル（JPG / PNG）スキャナ取り込み。A3以下なら 300dpi・グレースケールが最もきれいに残ります。
PDFCAD出力やスキャンPDF。ページを選んで取り込みます。元のPDFも一緒に保管され、版の履歴からいつでも取り出せます。
SVG（ベクター）CADやIllustratorからの書き出し。線のまま保持され、拡大しても劣化しません。文字化けの心配もないので、CAD出力があるならこれが最良です。
3Dモデル（GLB / glTF）BIM・SketchUp・Blenderからの書き出し。パースとして回して見られ、モデルの表面に指摘を打てます。
撮影のコツ①真上から ②蛍光灯の映り込みを避ける ③図面枠の四隅を画面内に ④明るい場所で。四隅がうまく合わないときは「補正しない」にして、スキャナ取り込みに切り替えてください。

03 / REVIEW検図を回す

ここがこのツールの本体です。図面の位置を指したまま指摘を交わし、対応状況を追いかけます。

版を取り込む→ 指摘を打つ→ 返信する→ 完了にする→ 次の版へ

指摘を打つ

図面カード →「図面を見る」→ 指摘を打つを押してから図面上をタップ。その座標にピンが刺さります。分類（意匠・構造・設備・法規）、件名、内容、担当、回答期限を入れて起票します。3Dパースの上でも同じように打てて、そのとき見ていたアングルごと保存されます。

指摘に答える

下タブの指摘から一覧を開き、返信を書きます。対応の進み具合は 未対応 対応中 完了 で切り替え。一覧は「自分宛」「期限超過」で絞り込めます。期限を過ぎたものは赤く出ます。

赤入れする

図面カード →「赤入れ」。ペン・直線・引出し・矩形・雲マーク・文字が引けます。色は朱／紺／緑／黒、太さは3段階。他の人が描いた線も選んで動かせる・消せるので、原図はそのままに、修正案を重ねて共同で詰めていけます。

04 / TOOLS効いてくる機能

版を比較旧版を朱・新版を紺で重ねる／境界を動かすワイプ／並べての3通り。さらに「変更箇所に雲マーク」を押すと、変わった範囲を検出して改訂雲を自動で打ちます。撮影のずれは自動で位置合わせしてから比べるので、紙がずれて写っただけの箇所は拾いません。加わった線と消えた線は分けて数えます。
AI検図Claude が図面を読み、法規・納まり・整合・設備の取り合いの観点で指摘候補を挙げます。候補は採用するまで記録されません。採用したものだけが指摘として起票され、同時に図面のその範囲へ改訂雲と件名が入ります。
3D パース図面カードの中で図面とワンボタンで切り替わります。パース／アイソメ、南・東・北・西・上からの視点。今見ているアングルをパース画像として版に保存できるので、そのまま赤入れに回せます。
関連図面平面図と立面図のように連動する図面を登録しておくと、片方に新しい版が上がった瞬間、もう片方に 要確認 が自動で立ちます。図面間の不整合は事故の定番なので、最初に組んでおく価値があります。
検図結果図面ごとに 承認／条件付承認／要修正 を所見つきで記録します。図面リストにも結果が出るので、どこまで固まったか一覧で分かります。
発行セットある時点の全図面の版をまとめて凍結し、発行日と宛先つきで記録します。確認申請・見積・施工で「いつ誰にどの版を渡したか」は後から必ず問われます。図面目録はCSVで書き出せます。
検図リスト指摘の一覧をCSVで書き出します。Excelでそのまま開ける形式なので、打合せ資料や是正指示書に転用できます。
BCFで書き出す指摘一式を BCF 2.1（buildingSMART の指摘交換の標準形式）で書き出します。Revit・Navisworks・Solibri・BIMcollab がそのまま読み込めるので、BIM側で作業している人に指摘を渡せます。件名・内容・分類・状態・担当・期限・返信がそのまま対応し、3Dの指摘はカメラのアングルごと渡るので、受け取った側は同じ視点で開けます。2Dの指摘には、図面にピンを描いた画像が付きます。

05 / SHARING共有と権限

アプリの右上の共有メニューから相手を追加します。付けた権限によって、アプリ内でできることが変わります。

権限できること
閲覧可オープンな工事の図面を見る。指摘を書く・返信する・状態を変える。赤入れする。
編集可上のすべてに加えて、図面の取り込み（撮影・画像・PDF・SVG・3Dモデル）と、プライベートな工事の閲覧。

工事の公開範囲をプライベートにすると、その工事は「編集可」の人だけが読み書きできる領域に保管されます。閲覧可の人には、図面も指摘も存在ごと返りません。表示上隠しているのではなく、サーバー側で弾いています。

06 / LIMITS気をつけること

社外の人には渡せません図面と指摘を保存する共有データベースを使う都合上、共有できるのは同じ組織にサインインしている人だけです。施主や施工者へ渡す用途は、今の構成では想定していません。
担当者名は自己申告です閲覧者を識別する仕組みがないため、記録に残る名前は各自が設定画面で入力したものです。検図の記録としては十分回りますが、「誰が承認したか」を法的に主張する用途には耐えません。
AI検図の結果は候補です採用操作を経るまで記録には入りません。内容は必ず人の目で確かめてから採用してください。図面から読み取れないことは確認依頼として書くよう指示していますが、誤りは起こります。
3Dモデルは約14MBまでDraco圧縮とKTX2テクスチャには対応していません。重いモデルは不要オブジェクトを削るか、テクスチャを縮小して書き出してください。PDFはフォントが埋め込まれていないと文字が欠けることがあります。その場合はSVG書き出しに切り替えてください。
